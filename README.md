# Daily Rashi Horoscope Generator (GitHub Actions, no backend)

Computes real Vedic transits via Swiss Ephemeris + classical Gochara rules,
has Gemini write short prose from that real data, and publishes one JSON
file a day via GitHub Pages -- no server, no hosting cost.

See the setup walkthrough provided alongside this file for step-by-step
instructions. Once set up, your daily JSON will be available at:

`https://<your-username>.github.io/<your-repo-name>/horoscope/latest.json`
